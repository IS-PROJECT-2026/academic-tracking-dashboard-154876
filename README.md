# academic-tracking-dashboard-154876
The Academic Tracking System is a web-based application designed to help students and lecturers manage and monitor academic performance. The system provides separate functionality for students and lecturers.

Student functionality

Students can:

View their registered courses.
View marks and grades for each course.
View grade points.
View their GPA and overall average.
Monitor their academic performance through dashboard statistics.
Identify passed courses and overall performance trends.
Lecturer functionality

Lecturers can:

Select the courses they teach.
View students enrolled in a course.
Enter or modify student marks.
Automatically calculate grades based on marks.
Calculate course averages.
View statistics such as highest mark, lowest mark and pass rate.
View the distribution of grades within a course.

Technology used
HTML,CSS and JavaScript
